# Feedback Hub – Original Repository

This is the **original repository** used for the Full-Stack Vibe Coding + Git Workflow Challenge.  
It acts as the **upstream source** for demonstrating Git collaboration steps such as:

- Forking the repository  
- Cloning the fork  
- Creating feature branches  
- Making commits  
- Opening Pull Requests (PRs)  
- Simulating merge conflicts  
- Resolving conflicts locally and merging PRs  

## Purpose of This Repository

This repository contains minimal content (only this README) so that students can:

1. Fork it into their own GitHub account  
2. Clone the fork locally  
3. Contribute changes from a feature branch  
4. Submit a Pull Request back to this original repo  
5. Experience and resolve merge conflicts  

The repository does **not** contain the full feedback application code.  
It exists solely to support the **Git workflow portion** of the assignment.

## Student Instructions

1. **Fork** this repository  
2. **Clone** your fork  
3. Create a **feature branch**  
4. Add a small change in this README (e.g., a new section)  
5. **Commit and push** your changes  
6. Open a **Pull Request** back to this original repo  
7. Simulate a **merge conflict** by modifying the same line in the original repo  
8. Resolve the conflict locally and merge the PR  

This README is intentionally simple so that it is easy to modify and conflict with.
